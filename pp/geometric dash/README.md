# Geometric Dash

A small 2D platform-style prototype made with **Python** and **Pygame**.

## Overview

The project displays a player character, a ground/platform, and a background. The player can jump when standing on the ground.

## Controls

- **Space:** jump
- **Close the window:** quit the game

## Requirements

- Python 3
- Pygame

Install Pygame with:

```bash
python -m pip install pygame
```

## Run

Run the script from the repository root so that the relative image paths resolve:

```bash
python "pp/geometric dash/main.py"
```

## Concepts practiced

- Game loop and event handling
- Classes and object state
- Basic gravity and jump movement
- Collision with a ground boundary
- Loading and scaling images

## Status

Basic prototype. The current implementation focuses on movement and rendering; it does not yet include the full obstacle and scoring mechanics of a finished endless-runner game.
