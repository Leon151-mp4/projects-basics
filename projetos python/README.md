# Python Projects

A collection of small Python exercises and desktop application experiments.

## Projects

| File | Description | Main technologies |
| --- | --- | --- |
| `tcalculadora.py` | Terminal calculator for two numbers and basic arithmetic operations. | Python, `input()`, conditionals |
| `CALCULADORA DE PESO.py` | Desktop form that multiplies height, width, and depth by a fixed factor. | Python, Tkinter, ttk |
| `Calculadora.py` | Early desktop calculator interface experiment. | Python, CustomTkinter |
| `Vidade.py` | Desktop form that accepts and displays an age value, with input validation. | Python, CustomTkinter |

## Requirements

- Python 3
- Tkinter (usually included with many Python distributions)
- CustomTkinter for `Calculadora.py` and `Vidade.py`

Install CustomTkinter with:

```bash
python -m pip install customtkinter
```

## Run

Run a script from the repository root. For example:

```bash
python "projetos python/tcalculadora.py"
python "projetos python/Vidade.py"
```

Replace the filename with the project you want to run.

## Concepts practiced

- User input and numeric conversion
- Conditional statements
- Functions
- Exception handling
- Basic graphical interfaces
- Input validation

## Notes

These are independent learning exercises. Some interfaces are prototypes and may be incomplete; each script should be run separately.
