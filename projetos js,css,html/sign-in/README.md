# Sign-in Form

A front-end sign-in form prototype built with **HTML**, **CSS**, and **JavaScript**.

## Overview

The form collects a name, email address, password, and password confirmation. JavaScript checks for empty fields and compares the two password values, then displays feedback beside the inputs.

## Run

Open `index.html` in a browser. A local development server is recommended during development.

## Technologies

- HTML
- CSS
- JavaScript

## Concepts practiced

- Form layout and labels
- DOM selection
- Arrays and iteration
- Click event handling
- Input validation and conditional logic
- Updating text and styles through JavaScript

## Status and limitations

This is a front-end practice project, not a complete authentication system. It does not create accounts, send credentials to a server, or securely store passwords. The current validation is client-side only.
