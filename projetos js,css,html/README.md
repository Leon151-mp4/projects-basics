# Web Projects

A collection of beginner projects made with **HTML**, **CSS**, and **JavaScript**.

## Projects

| Folder | Description |
| --- | --- |
| [Previsão do tempo](Previs%C3%A3o%20do%20tempo/) | Weather interface prototype; API integration is still in progress. |
| [calculadora](calculadora/) | Browser calculator with basic arithmetic operations. |
| [sign-in](sign-in/) | Front-end form with basic field and password-match validation. |

## Run

Open the `index.html` file inside the project folder you want to try. A local development server is recommended for development.

Each folder is an independent project and has its own README with more details.
