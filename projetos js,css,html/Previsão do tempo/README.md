# Weather Forecast

A browser-based weather interface prototype built with **HTML**, **CSS**, and **JavaScript**.

## Overview

The page contains a weather-themed interface with a temperature area and navigation controls. The JavaScript file currently contains an early API integration draft.

## Run

Open `index.html` in a browser. For development, a local server such as VS Code Live Server is recommended.

## Technologies

- HTML
- CSS
- JavaScript
- OpenWeather API (integration is currently incomplete)

## Concepts practiced

- HTML page structure
- CSS styling and layout
- Selecting and manipulating DOM elements
- Beginning work with an external API

## Status and configuration

This project is a work in progress. The current JavaScript does not yet complete an API request or update the interface with live weather data.

If you continue the API integration, keep the API key in a local configuration file and do not commit secrets to a public repository. Use a placeholder in any example configuration shared publicly.
