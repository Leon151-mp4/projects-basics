# Calculator

A simple calculator interface built with **HTML**, **CSS**, and **JavaScript**.

## Features

- Number and operator buttons
- Clear the display
- Delete the last entered character
- Evaluate basic arithmetic expressions
- Convert percentage input to division by 100

## Run

Open `esqueleto.html` in a browser. A local development server is recommended while editing the project.

## Technologies

- HTML
- CSS
- JavaScript

## Concepts practiced

- DOM selection
- Event listeners
- Iterating over a collection of buttons
- Updating an input field
- Basic error handling with `try/catch`

## Status

Basic learning project. The current implementation evaluates the expression entered in the display; it should not be treated as a secure calculator for untrusted input.
